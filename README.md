# Weather & Loan Data ETL Practice :

Small ETL (Extract, Transform, Load) scripts built while learning data engineering fundamentals.

## Whats here :
- `fetch_weather.py` — pulls live weather data from a public API, cleans it, and stores it in MySQL
- `explore_pandas.py` — practice cleaning messy data with pandas (fixing inconsistent text, whitespace, missing values)

## Tech used :
Python, pandas, pymysql, MySQL, the Open-Meteo public API

## What I learned :
- Reading data from files and live APIs
- Cleaning inconsistent/messy real-world data
- Connecting Python to a database securely (parameterized queries)
- The Extract → Transform → Load pattern end to end
